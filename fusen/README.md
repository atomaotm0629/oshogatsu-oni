# ふうせんバトル（家族ゲーム03）

テレビ（PCの画面）に映して、みんなは自分のスマホで操作する対戦ゲームです。
iPhone・Androidのブラウザで動きます。アプリのインストールは要りません。

## 遊び方
1. PCでこのページを開き、テレビに映す
2. 各自のスマホでQRコードを読み取り、名前を入れて参加
3. スマホを傾けて運転（指でなぞってもOK）。ふうせんは3つ
4. プレゼント箱でアイテムを取り、スマホの黄色いボタンで使う
   - まきびし：後ろに置く
   - こま：まっすぐ飛んで壁で跳ね返る（自分にも当たる）
   - 紙ひこうき：近くの相手を追いかける
   - ロケット花火：加速。体当たりすると相手のふうせんを奪える
5. ふうせんが全部われたら「おばけ」になり、ブロックをすり抜けて、残っている人を1回だけおどかせる
6. 最後までふうせんが残った人の勝ち（2分で時間切れ → ふうせんの多い順）

- 最大8人。人数が足りないときはCPUを追加できます
- PCのキーボードで1人参加できます（矢印キー/WASDで運転、スペースでアイテム）
- 傾きセンサーは https のページでしか使えません
