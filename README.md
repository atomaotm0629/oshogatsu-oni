# お正月ゲーム広間

テレビ（PCの画面）に映して、みんなは自分のスマホで操作するお正月向けのミニゲーム集です。
iPhone・Androidのブラウザで動きます。アプリのインストールは要りません。

公開ページ: https://atomaotm0629.github.io/oshogatsu-oni/ （トップがゲーム一覧）

## ゲーム
- [お正月オニごっこ](oni/)：スマホを傾けて逃げ回る鬼ごっこ。鬼にタッチされたら鬼交代（最大8人）
- [わっしょい！おみこしリズム](omikoshi/)：紅白2チームの音はめゲーム。太鼓に合わせてスマホを振ると、おみこしが進む（最大16人）
- [ふうせんバトル](fusen/)：カートに乗って、ふうせんを割り合う対戦ゲーム。アイテムを拾って使う（最大8人）

## 遊び方（共通）
1. PCでゲーム一覧を開き、遊ぶゲームを選んでテレビに映す
2. 各自のスマホでQRコードを読み取り、名前を入れて参加
3. 終わったら、テレビ側の「ゲーム一覧」ボタンで次のゲームへ（部屋番号が変わるので、スマホは新しいQRで入り直す）

- 通信が切れたときは、画面の下に出る「再読み込み」ボタンで入り直せます
- スマホとテレビ画面は直接つながります（最初の接続だけ PeerJS の無料サーバーを使用）
- 傾きセンサーは https のページでしか使えません
