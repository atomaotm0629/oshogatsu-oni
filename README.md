# お正月オニごっこ

テレビ（PCの画面）に映して、みんなは自分のスマホで操作するお正月向けのミニゲームです。
iPhone・Androidのブラウザで動きます。アプリのインストールは要りません。

## 遊び方
1. PCでこのページを開き、テレビに映す
2. 各自のスマホでQRコードを読み取り、名前を入れて参加
3. スマホを傾けて動く（指でなぞってもOK）。鬼にタッチされたら鬼交代
4. 60秒後、鬼だった時間が短い人の勝ち

- 最大8人。人数が足りないときはCPUを追加できます
- スマホとテレビ画面は直接つながります（最初の接続だけ PeerJS の無料サーバーを使用）
- 傾きセンサーは https のページでしか使えません
